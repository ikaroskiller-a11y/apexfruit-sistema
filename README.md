# Apex Fruit

Sistema de gestión de calidad e inspección de fruta para Apex Fruit.

## Estructura del proyecto

```
ApexFruit/
├── docs/
│   ├── research/   → Investigación de mercado, funcionalidades y estándares de inspección
│   └── design/      → Identidad visual, mockups y guía de diseño
├── apps/
│   └── web/          → Aplicación web (dashboard, inspecciones, reportes, gráficos)
└── packages/         → Código compartido (tipos, utilidades) entre apps futuras (web/móvil/api)
```

## Estado

Proyecto en arranque — MVP en construcción. Ver `docs/research/` para el alcance funcional y `docs/design/` para la identidad visual.

## Flujo de trabajo

- Desarrollo local en esta carpeta.
- `git push` sincroniza con el repositorio remoto en GitHub para compartir avances con el equipo/programador.
